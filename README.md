## 🎯 포커스 앵커 기반 과목별 학습 관리 시스템

### 📌 프로젝트 소개
이 프로젝트는 공부 중 쉽게 흐트러지는 집중 흐름을 유지하고, 과목별 일정과 할 일을 체계적으로 관리할 수 있도록 돕는 학습 지원 소프트웨어이다. 

단순한 캘린더 또는 투두 앱이 아니라, **공부 흐름 유지 + 과목 중심 계획 관리 + 떠오르는 생각의 즉시 기록**을 통합적으로 지원하는 것을 목표로 한다.

### 🌱 개발 배경
학과 특성상 노트북을 활용하여 과제, 복습, 자료 조사 등 다양한 학습 활동을 수행하는 경우가 많다. 그러나 공부를 하다 보면 학습과 관련된 일을 하던 중에도 다른 대화나 웹 탐색으로 쉽게 주의가 분산된다. 예를 들어 과제를 하다가 친구에게 잠시 질문을 하려 했지만 대화가 길어져 30분 이상 흐르는 경우처럼, 본래의 학습 흐름이 자주 끊기는 문제가 발생한다.

또한 공부를 하다가 갑자기 떠오르는 해야 할 일을 바로 기록하지 못해 잊어버리는 경우도 많다.  혹은 해야 할 일을 바로 하다가 원래 하던 일을 잊어버리는 경우도 잦다. 

기존의 캘린더나 투두 앱은 일정 관리 기능은 제공하지만, 과목별로 세분화된 학습 계획과 할 일을 구조적으로 관리하거나, 학습 집중 흐름과 연결하여 지원하는 기능은 부족하다고 느꼈다.

이러한 나와 기존 서비스의 아쉬운 점을 보완하기 위해, **집중 이탈을 줄이고 학습 중 떠오른 생각을 즉시 기록하며, 과목별 일정과 세부 할 일을 한 번에 관리할 수 있는 학습 지원 시스템**을 기획하였다.

### 🎯 프로젝트 목표
- 사용자가 학습 중 불필요하게 흐름을 잃지 않도록 도와주는 집중 보조 기능 제공
- 과목별로 학습 일정과 할 일을 구조적으로 관리할 수 있는 환경 제공
- 공부 중 떠오르는 추가 할 일을 빠르게 기록하여 잊지 않도록 지원
- 캘린더와 투두 기능을 결합하여 과목별 학습 계획을 한눈에 확인 가능하도록 구현

### ✨ 핵심 기능

1. **포커스 앵커 기능**
- 공부 시작 전 사용자가 '소프트웨어공학 HW1 작성' 과 같은 한 줄 목표를 입력
- 입력된 선언문을 웹 화면 상단의 고정 위젯 형태로 표시
- 일정 시간이 지나면 선언문을 다시 보여주어 학습 흐름을 부드럽게 리마인드
- 뽀모도로 기능과 연계하여 집중 시간과 휴식 시간을 함께 관리

2. **브레인 덤프 사이드바 기능**
- 공부 중 갑자기 떠오른 해야 할 일이나 생각을 즉시 기록할 수 있는 사이드바 제공
- 현재 하던 공부를 중단하지 않고도 새로운 생각을 빠르게 저장 가능
- 기록한 내용은 미분류 상태로 보관하거나, 이후 특정 과목 카테고리나 일정에 연결 가능

3. **과목별 카테고리 관리 기능**
- 과목별 카테고리 생성 가능
- 각 카테고리마다 일정, 투두, 반복 학습 계획, 세부 투두를 구분하여 관리
- 반복 일정 수정 시 '이번만 수정' 또는 '전체 수정' 방식 제공
- 캘린더에서 카테고리 필터를 통해 원하는 과목의 일정만 선택적으로 확인 가능

4. **일정 내부 드릴다운 기능**
- 사용자가 특정 일정을 클릭하면 해당 일정 내부에서 세부 할 일과 메모를 바로 확인하고 수정 가능
- 하나의 일정 안에 여러 개의 하위 투두를 구성하여 큰 과제를 작은 실행 단위로 분리 가능

5. **흐름 타임라인 기능**
- 포커스 앵커와 뽀모도로 기능을 통해 기록된 집중 정보를 바탕으로 하루 동안 과목별 학습 시간을 흐름 형태로 시각화
- 사용자가 하루의 학습 패턴을 이해하고 자신의 학습 흐름을 복기할 수 있도록 지원

### 🌟 기대 효과
- 공부 중 쉽게 새는 흐름을 줄여 학습 집중도 향상
- 과목별 일정과 할 일을 체계적으로 정리 가능
- 갑자기 떠오른 해야 할 일을 놓치지 않고 기록 가능

### 🛠 개발 예정 기술 스택
| 구분 | 기술 | 사용 목적 |
|------|------|-----------|
| Frontend | React | 동적인 캘린더 및 사이드바 UI를 구현하기 위해 사용 |
| Backend | Spring Boot | 일정, 투두, 카테고리 등의 데이터를 안정적으로 관리하기 위해 사용 |
| Database | MySQL | 학습 관련 데이터를 구조적으로 저장하기 위해 사용 |
| Design | Figma | 화면 설계 및 UI 흐름 구성을 위해 사용 |
| Collaboration | GitHub | 버전 관리 및 프로젝트 문서화를 위해 사용 |



### 👣 예상 사용자 흐름
1. 사용자는 과목별 카테고리를 생성한다.
2. 카테고리 안에 반복 일정, 일반 투두, 세부 투두를 등록한다.
3. 공부를 시작하기 전 캘린더의 카테고리 필터를 활용하여 일정을 간단하게 확인한다.
4. 포커스 앵커에 현재 목표를 입력하고 뽀모도로를 시작한다.
5. 공부 중 떠오른 생각은 브레인 덤프 사이드바에 기록한다.
6. 필요한 경우 해당 메모를 과목 카테고리에 연결한다.
7. 하루가 끝난 뒤 흐름 타임라인을 통해 과목별 학습 패턴을 확인한다.
